# Ghost Editor (`ghost-editor`)

Packaged from [`kurbaitaev/ghost-editor`](https://github.com/kurbaitaev/ghost-editor) (MIT) for the REA Enhanced Antigravity Pack.

- **Skill:** `ghost-editor` — turns raw talking-head footage into finished 1080x1920 Reels / TikToks / Shorts with automatic take selection, pause removal, face tracking, 19 named visual style recipes (`Clean OS`, `Seoul list`, `RESULT`, `Face RESULT`, `Whiteboard`, `Kinetic doc`, `Step Deck`, `Product page`, `Tactile paper`, `Caption News`, `News Package`, `Telestrator`, `Halftone Dossier`, `Swiss Grid`, `Data Story`, `Hologram HUD`, `stan style`, `vector explainer`, `POV montage`), approval sheets, and render QA.
- **Note:** Downloadable SFX/meme/music media (`library/`) and showcase GIFs are omitted from git to keep the repository lightweight; run `python3 scripts/library_restore.py` on first use when needed.
