# Whisper Auto Captions (`whisper-captions`)

Local speech-to-text transcription and word-timed auto-caption formatter for the REA Enhanced Antigravity Pack (MIT).

- **Skill:** `whisper-captions` — backend discovery (`faster-whisper`, `whisperx`, `openai-whisper`, `mlx-whisper`), model selection, VAD filtering, vertical 9:16 vs. 16:9 readability rules, and FFmpeg/Remotion/HyperFrames handoff.
- **Bundled CLI:** `skills/whisper-captions/scripts/whisper_captions.py` (stdlib-only `--doctor` and `--from-words` exporter generating `.srt`, `.vtt`, `.captions.json`, and `.ass` viral word-pop / karaoke subtitles).
