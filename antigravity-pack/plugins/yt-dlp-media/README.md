# yt-dlp Media Downloader (`yt-dlp-media`)

Zero-API-key media, audio, subtitle, time-range clip, and metadata downloader skill powered by `yt-dlp` for the REA Enhanced Antigravity Pack (MIT).

- **Skill:** `yt-dlp-media` — edit-ready H.264/AAC MP4 downloads, audio extraction for `whisper-captions`, subtitle-only fetching, `--download-sections` time-range clipping, and `--dump-json` metadata inspection.
- **Bundled CLI:** `skills/yt-dlp-media/scripts/yt_dlp_helper.py` (stdlib-only, `shell=False` execution, `--doctor`, and `--dry-run` command planning).
