# HyperFrames Motion Graphics Studio (`hyperframes` v0.9.104)

Official **HyperFrames by HeyGen** Agent Skills suite (`v0.9.104`, **Apache-2.0**) from [`heygen-com/hyperframes`](https://github.com/heygen-com/hyperframes) packaged for the REA Enhanced Antigravity Pack:

- **`hyperframes`** — Master HTML-to-video motion graphics router, deterministic frame-seeking render contract, and bundled CLI launcher (`scripts/plugin-cli.mjs`)
- **`hyperframes-cli`** — Scaffolding, validation (`check`), snapshots, preview, rendering, and project history
- **`hyperframes-registry`** — ~450 ready-made editable motion graphics blocks (kinetic type, charts, map overlays, transitions, CRT/glitch/film grain, 3D)
- **`media-use`** — Audio, SFX, BGM, icons, cutouts, color grades, voiceovers, and transcripts
- **`remotion-to-hyperframes`** — Frame-by-frame porting from Remotion, Lottie, Three.js, Manim, or After Effects
- **`reverse-any-video`** — Rebuild any reference video as an editable HyperFrames project
- **`style-sampling`** — Produce new episodes in proven explainer & documentary styles
- **`slideshow`** — Interactive live HTML presentation decks (`hyperframes present`)
- **`figma`** — Bring Figma designs, frames, and brand tokens into HyperFrames motion
